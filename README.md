---

## 📖 Descripción

Este repositorio contiene el código fuente y los archivos necesarios para el desarrollo de un juego interactivo de código secreto utilizando el microcontrolador STM32F411.

El sistema permite al usuario participar en un juego de adivinación de códigos mediante potenciómetros, incorporando diferentes elementos electrónicos para la interacción y visualización de resultados.

El proyecto integra distintos periféricos del microcontrolador para implementar las funcionalidades del juego.

### ⚙️ Funcionalidades y componentes

- **Potenciómetros:** introducción y ajuste de valores del código.
- **LEDs:** señalización visual del estado del juego.
- **Display de 7 segmentos:** visualización de información.
- **Zumbadores:** generación de señales acústicas.
- **Botones:** control de las distintas funcionalidades del juego.

## 📁 Estructura del repositorio

El proyecto se organiza siguiendo la estructura generada por STM32CubeIDE:

- `Core/`: código principal de la aplicación, incluyendo los archivos fuente y cabeceras.
- `Drivers/`: controladores y bibliotecas necesarias para el funcionamiento del microcontrolador.
- `.ioc`: archivo de configuración del proyecto y de sus periféricos.
- `README.md`: descripción general y documentación del repositorio.
